# 📂 Sample Data

โฟลเดอร์นี้สำหรับเก็บ sample documents ที่จะใช้ใน Day 1

## ไฟล์ที่ต้องเตรียม

วาง documents ของคุณที่นี่ รูปแบบที่รองรับ:
- `.pdf` — เอกสาร PDF
- `.docx` — เอกสาร Word
- `.txt` — ข้อความธรรมดา

## ตัวอย่าง Documents ที่แนะนำ

หากไม่มีเอกสารของตัวเอง ให้ใช้ตัวอย่างเหล่านี้:

### 1. คู่มือพนักงาน (Employee Handbook)
ดาวน์โหลดตัวอย่างจากแหล่งสาธารณะ หรือสร้างเองด้วย:
```python
# สร้าง sample text file
sample_text = """
บริษัท X-Company
คู่มือพนักงาน ปี 2566

ข้อ 1 เวลาทำงาน
พนักงานมีเวลาทำงานปกติวันจันทร์ถึงศุกร์ เวลา 08:30 - 17:30 น.

ข้อ 2 วันหยุด
พนักงานได้รับวันหยุดพักผ่อนประจำปี 10 วันต่อปี
...
"""
with open("employee_handbook.txt", "w", encoding="utf-8") as f:
    f.write(sample_text)
```

### 2. นโยบายการลา
สร้างไฟล์ `leave_policy.txt` ด้วยเนื้อหานโยบายการลาของบริษัทคุณ

### 3. คู่มือ IT
สร้างไฟล์ `it_manual.txt` ด้วยขั้นตอนการขอใช้อุปกรณ์ IT

## โครงสร้างที่แนะนำ

```
sample_data/
├── README.md            # ไฟล์นี้
├── employee_handbook.txt
├── leave_policy.txt
├── it_manual.txt
└── safety_manual.txt
```

## ⚠️ หมายเหตุ

- ไม่ต้อง commit ไฟล์ข้อมูลจริงขึ้น GitHub (มี .gitignore แล้ว)
- ใช้เอกสารที่ไม่มีข้อมูลส่วนบุคคลในการทดสอบ
- ขนาดไฟล์แนะนำ: 1-10 MB ต่อไฟล์
